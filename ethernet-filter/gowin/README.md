# Сборка в Gowin EDA

Создайте проект для `GW1NR-LV9QN88PC6/I5`, затем добавьте исходники в следующем порядке:

1. `rtl/linear_regression_classifier.v`
2. `rtl/rmii_filter_channel.v`
3. `rtl/gowin_ethernet_filter_top.v` — top module `gowin_ethernet_filter_top`
4. `constraints/ethernet_filter.sdc`

Синтезируемый дизайн использует две памяти `2 x 1530 x 8` бит; у каждой направление одна память с синхронным чтением, чтобы инструмент Gowin мог отобразить буферы в BSRAM. После синтеза проверьте utilization report и что память не разложилась целиком на LUT.

Для размещения платы задайте выводы в `.cst` по фактической разводке PCB. Здесь pin assignments намеренно не заданы: корпус QN88 в исходной спецификации не имеет утверждённой карты сигналов, а назначение выводов до выбора трассировки было бы выдуманным. RMII I/O должны быть 3,3 В, входной `ref_clk_50m` — стабильный 50 MHz.

Добавьте в timing constraints задержки RXD/CRS_DV/RXER относительно PHY REF_CLK и TXD/TX_EN к PHY по datasheet выбранного LAN8742A и учитывая fanout clock buffer. Одного `ethernet_filter.sdc` достаточно только для объявления периода такта, не для окончательной статической проверки timing.

Параметры модели задаются при инстанцировании верхнего модуля. Запустите CSV-обучатель и перенесите сгенерированные `.MODEL_W_*` и `.MODEL_THRESHOLD` в параметрический список top-level instance. После этого повторно выполните synthesis и place-and-route, сохраните `.fs` битстрим и запрограммируйте FPGA через JTAG или поддерживаемый режим конфигурации.

PHY reset, MDIO/MDC и сигналы `phy*_link_100fd` подключите к STM32G0B1: MCU настраивает рекламируемый режим PHY, проверяет что оба линка подняты на 100BASE-TX full-duplex, а затем разрешает передачу соответствующим входом FPGA. FPGA блокирует/передаёт сами кадры; MCU не участвует в классификации.
